### 🌟 About Verto
Step into the world of open-source with **Verto**! We carefully curate popular projects with easy-to-tackle issues, making it simple for developers—especially beginners—to find their first project to contribute to. 

**Verto** is more than just a list; it's a platform where:
- **Beginners** make their first real-world contribution.
- **Founders** build a solid, diverse team of contributors.
- **Maintainers** discover new talent to help scale their projects.

Your code today could be the spark that starts an amazing journey in the open-source community.

### 🛠️ Quick Start: Contribute Your First Project
Want to help others find great projects? Adding a new project to Verto is simple!

#### 📋 Project Criteria
To maintain high quality, projects must meet these requirements:
- **GitHub:** $\ge$ 3 issues with `good first issue` (or labels in `config.json`).
- **GitLab:** $\ge$ 3 issues with `quick win` (or labels in `config.json`).
- **Community:** $\ge$ 10 contributors.
- **Popularity:** $\ge$ 1000 stars.
- **Quality:** Must have a detailed `README.md` (setup instructions) and a `CONTRIBUTING.md`.
- **Activity:** Last update must be within the last month.

#### 🚀 How to Add a Project
1. **GitHub:** Add the repository path (`owner/name`) in lexicographic order to [config.json](config.json) under the `GitHub` provider.
2. **GitLab:** Add the project ID (`<project path>|<project id>`) to [config.json](config.json) under the `GitLab` provider.
3. **Submit:** Create a Pull Request. **Important:** Include a link to the project's issues page in the PR description.

Once merged, your project will be live at [verto.lucavallin.com](https://verto.lucavallin.com).

### ⚙️ Technical Overview
**Verto** is built with a modern tech stack for speed and scalability:
- **Framework:** Next.js, React, and TypeScript.
- **Data Flow:** Data is loaded from `data.json`, which is dynamically generated by [data/utils.ts](data/utils.ts) via GitHub and GitLab APIs.
- **Filtering:** Labels defined in `config.json` are used to filter and categorize issues.

#### 💻 Local Setup
Follow these steps to run Verto locally and start contributing:

1. **Environment:** Ensure you have a recent version of Node.js installed.
2. **Clone & Branch:**
   ```bash
   git clone https://github.com/lucavallin/verto.git
   cd verto
   git checkout -b feature/your-feature-name
   ```
3. **Dependencies:**
   ```bash
   npm install
   ```
4. **Data Fetching:** Use the provided `data.json` or fetch fresh data:
   - Set the `GH_PAT` environment variable to your GitHub Personal Access Token.
   - Run: `npm run prebuild`
5. **Launch:**
   ```bash
   npm run dev
   ```
   Open your browser to `http://localhost:3000`.

> **Pro Tip:** The project uses a `pre-commit` hook to automatically run linters, ensuring your code stays clean!
